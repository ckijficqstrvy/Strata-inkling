四大推薦使用情境

依據不同任務挑選最適合的模式與客戶端，讓 RX 6700 XT 發揮最大戰力：

💬 1. 日常繁體中文問答、寫作與翻譯

直接點「開啟 Strata 網頁聊天室」，免裝外掛即享多輪串流對話、歷史紀錄與即時速度顯示。

推薦：極速全能模式 溫度 1.0 ~25.4 tok/s

📄 2. 長文件閱讀與重點摘要（2K–32K）

貼上長篇技術文件、會議紀錄或論文段落做重點整理；k8v8 在 5.2K 長文下依然穩定 100% 駐留顯存。

推薦：極速全能模式 32K 上下文 Prefill 110 / Decode 22.7 tok/s

💻 3. IDE 寫程式與 AI 外掛串接

可接入 Cline、Roo Code、Continue、Cherry Studio、Open WebUI 等任何 OpenAI 相容工具；大量跑英文補全時可切至低溫 DSpark 模式衝 30+ tok/s。

OpenAI /v1 API 模型名：inkling-2-mini-sq-10

🛠️ 4. Anthropic / Claude Code 協定串接

from openai import OpenAI

client = OpenAI(base_url="http://127.0.0.1:8081/v1", api_key="local")
resp = client.chat.completions.create(
    model="inkling-2-mini-sq-10",
    messages=[{"role": "user", "content": "請用繁體中文介紹快速排序法"}],
    temperature=1.0,
    max_tokens=1024,
)
print(resp.choices[0].message.content)

RX 6700 XT 實戰使用提醒

  • 避免顯存衝突：啟動本系統前，請先停止 G:\AI\Strata（Qwen）並確保 Ollama 未常駐大型模型，否則 12 GB 顯存不足會掉入混合模式而降速。
  • 適時限制輸出長度：Inkling-2-Mini 原生內含少量推理特性，串接外部 Agent 或自動化工具時建議設定 max_tokens（如 1024～4096），避免陷入過長思考迴圈。
  • 純文字省顯存設計：目前刻意不載入 0.64 GB 的 Vision 模組以保留完整 VRAM 空間；若日後需要看圖，下載 Inkling-2-Mini-Vision.strata 放進模型目錄並在設定檔加入 --vision 即可。
